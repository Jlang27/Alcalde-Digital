# Scripts de depuración

Herramientas sueltas que se usaron para diagnosticar un problema concreto
(un modelo tumbado, pies que patinan, un esqueleto distinto…). No son
pruebas de regresión: no hace falta correrlas antes de un commit.

Se ejecutan igual que los escenarios, desde la raíz del proyecto:

    .venv/bin/python herramientas/banco_pruebas/depuracion/quien_tirado.py
